EX03 — Identifier les adresses MAC et IP dans une communication locale
Objectif : Comprendre comment les adresses IP et MAC sont utilisées lorsque deux machines communiquent sur le même réseau local.

Travail à effectuer :
1. Sur ton ordinateur Ubuntu, ouvre Wireshark.
2. Sélectionne l'interface réseau que tu utilises.
3. Lance une capture de paquets.
4. Depuis le terminal, envoie des requêtes ping vers une autre machine de ton réseau local.
5. Arrête la capture et retrouve les paquets ICMP générés.
6. Dans les détails des paquets, identifie :
   - L'adresse IP source.
   - L'adresse IP destination.
   - L'adresse MAC source.
   - L'adresse MAC destination.
7. Explique la différence entre les adresses IP et MAC et précise leur rôle dans cette communication.
Livrable attendu :
- Une capture Wireshark montrant les paquets ICMP.
- Une capture ou annotation indiquant les quatre adresses.
- Une courte explication de leur rôle.
